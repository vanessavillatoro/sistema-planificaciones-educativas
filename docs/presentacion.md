# Presentación del Sistema de Planificaciones Educativas

## ¿Qué es el Sistema?
Sistema Pedagógico Generador de Planificaciones y Recursos Didácticos con Inteligencia Artificial para docentes en El Salvador.

## Problema que Resuelve
Los docentes dedican demasiado tiempo a crear planificaciones manualmente. Este sistema reduce ese tiempo utilizando IA para generar planificaciones completas en segundos.

---

## Funcionalidades Principales

### 1. Generación de Planificaciones
- Campo de departamento y municipio
- Nivel educativo: parvularia, 1er ciclo, 2do ciclo, 3er ciclo
- Materia y grado
- Sugerencias para la IA
- Output: planificación completa con indicadores, objetivos, ejes y secuencia

### 2. Generación de Recursos
- Descripción del tema
- Nivel de dificultad (refuerzo/ampliación)
- Output: fichas, cuestionarios, actividades

### 3. Gestión y Exportación
- Lista de planificaciones generadas
- Editar y eliminar
- Exportar a PDF y DOCX
