# Guía de Lanzamiento - Sistema de Planificaciones Educativas

## Información General

**Nombre del Sistema**: Sistema Pedagógico Generador de Planificaciones Educativas

**Descripción**: Sistema web que permite a docentes de El Salvador generar planificaciones y recursos didácticos utilizando inteligencia artificial.

**URL de Producción**: https://sistema-planificaciones-educativas-ten.vercel.app

**Fecha de Lanzamiento**: 27 de febrero de 2026

**Versión**: 1.0.0

## Acceso al Sistema

### Requisitos
- Navegador moderno (Chrome, Firefox, Edge, Safari)
- Conexión a internet
- Cuenta de docente (registro gratuito)

### Pasos para Registrarse
1. Acceder a la URL: https://sistema-planificaciones-educativas-ten.vercel.app
2. Clic en "Regístrate"
3. Completar formulario (nombre, apellido, correo, contraseña)
4. O usar Google Login para acceso rápido
5. ¡Listo! Ya puedes usar el sistema

### Pasos para Iniciar Sesión
1. Ir a la URL del sistema
2. Ingresar correo y contraseña
3. O clic en "Iniciar sesión con Google"
4. Redirección automática al dashboard

## Funcionalidades Principales

### Módulo 1: Generador de Planificaciones
- Seleccionar departamento y municipio
- Elegir nivel educativo (parvularia, 1er ciclo, 2do ciclo, 3er ciclo)
- Elegir materia y grado
- Escribir sugerencias para la IA
- Clic en "Generar Planificación"
- La IA genera planificación completa con indicadores, objetivos, ejes y secuencia

### Módulo 2: Generador de Recursos
- Seleccionar tipo de recurso
- Escribir descripción del tema
- Elegir nivel de dificultad (refuerzo o ampliación)
- Clic en "Generar Recurso"
- La IA genera recursos didácticos (fichas, cuestionarios, actividades)

### Módulo 3: Gestión y Exportación
- Ver todas las planificaciones generadas
- Editar planificaciones existentes
- Eliminar planificaciones no necesarias
- Exportar a PDF o DOCX
- Descarga directa
